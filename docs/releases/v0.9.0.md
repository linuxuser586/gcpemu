## Cloud Build

Cloud Build is the twelfth Product (ADR 0016). The Builds API v1 is served over gRPC and REST, on
`projects/*/builds` and `projects/*/locations/*/builds`, with create, get, list, cancel and retry.
Build steps run as containers in order or by `waitFor`, sharing `/workspace`. A Build's source is
a `storageSource` archive, as `gcloud builds submit` uploads it, or a public `gitSource`. Step logs
are written as they run to `log-BUILD_ID.txt` in the Build's `logsBucket`. `build.concurrency`
(default 4, `GCPEMU_BUILD_CONCURRENCY`) caps the Builds running at once. Cloud Build v2 answers
UNIMPLEMENTED.

Outside Host mode, run `gcloud builds submit` with `--async` or `options.logging: NONE`: gcloud's
log streaming ignores endpoint overrides. See "Cloud Build" in the README.

## Native Windows

`gcpemu.exe` now runs every Service natively, Cloud SQL, GKE, Cloud NAT and Cloud Build included,
on Docker Desktop or Podman machine in Linux-containers mode. It finds them on their named pipes
(`npipe://`), and you no longer need a WSL2 distribution. `gcpemu ca install` adds the CA to the
user's Root store. A port in one of Windows' excluded port ranges fails as unavailable. See
"Windows" in the README.

## The Google front end on the LAN

`--gfe-bind <address>` (repeatable, `gfeBind`) serves the Google front end on `<address>:443`,
for clients on another machine that call Google by its real hostnames and take no endpoint
override, such as Argo Workflows' GCS artifact driver (ADR 0021). Every request there must carry
credentials the Instance issued. Service account keys created through a real Google hostname work
unmodified from another machine. `gcpemu doctor` checks the addresses and port 443.

## Building from source: Task replaces make

The Makefile is gone (ADR 0018). Install [Task](https://taskfile.dev) and run `task build`,
`task agent` or `task release VERSION=vX.Y.Z` instead of the make targets. The tasks run from any
shell, PowerShell included.

## Also in this release

- Cloud SQL takes Final backups on instance delete (`--enable-final-backup`), `backups.list`
  takes gcloud's filters, and backups expire on the Emulator clock.
- API requests made while an Instance Reset or State snapshot restore runs are refused or cut off
  as UNAVAILABLE (HTTP 503 with `Retry-After`). Retry them.
- Pods labelled `gcpemu.dev/googleapis=real` resolve `*.googleapis.com` to real Google (ADR 0019).
- `gcpemu ca install` tells macOS users to restart Docker Desktop.
- On a VM runtime, a Containerized Instance publishes each public Cloud SQL instance on a
  `127.0.0.x` of its own.
