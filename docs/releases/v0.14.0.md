## Changed: Host mode's hostnames serve only public APIs

A request whose `Host` is one of Host mode's hostnames (a Service's or Delegated API's host, or
`www.googleapis.com`) never reaches the Admin API or the Web console any more: `/_emu/…` and
`/console…` there are public API paths, and `www.googleapis.com/console` answers Not Found (#890,
ADR 0052). Before, `firestore.googleapis.com/_emu/…` was forwarded to the External emulator with
the Admin token cookie, and `www.googleapis.com` served the console.

Reach the Admin API and the Web console at the API gateway's own address, as `gcpemu env` prints
it. A bucket named `console` is now reachable through Host mode on `storage.googleapis.com`.

## Changed: the API gateway drops cookies from public API requests

The Web console now sends same-origin cookies, so it works behind an Authenticating proxy such as
oauth2-proxy on the same origin (#888). In turn, the API gateway deletes `Cookie` from every request
that isn't an Admin API or Web console request, and from every request a Linked Instance forwards
(ADR 0052). Neither the Admin token nor a proxy's session reaches a Service, a cluster's
kube-apiserver, an External emulator or another Instance. No public API reads cookies: a Principal
comes only from an access token. Load balancer session affinity cookies are unaffected.

## Changed: Cloud CDN compression follows GCP's rules

With `compressionMode: AUTOMATIC`:

- Cloud CDN serves Brotli (`br`) when the client accepts it, and gzip otherwise (#907). A coding
  whose `q` weight is 0 is refused, and a refusal beats an acceptance of the same coding.
- Only a 200 with a `Content-Length` from 1 KiB to 10 MiB is compressed, and only for GCP's
  documented types: its exact list plus `text/*`, `application/*+json`, `application/*+xml` and
  `application/*mpegURL` (#908). A response without `Content-Length` is no longer compressed.
- A compressed response sends `Accept-Ranges: none`, and a GET answered from a cached object
  ignores `Range` and `If-Range` when it will be compressed: the client gets 200 with the whole
  compressed object instead of 206 (ADR 0054). A response that won't be compressed still gets its
  range.
- A cached object stored without a `Content-Type` is answered without one, and so isn't
  compressed.

## GKE reissues the Cluster server's serving certificate on every start

The Cluster server's serving certificate is now reissued on every start, and a cluster goes
RUNNING only once the server's certificate names its Public endpoint (#886, ADR 0051). After the
External network moved, a cluster could briefly serve a certificate for its old address; that is
the `TestPublicEndpointMoves` flake the v0.13.0 release PR listed.
